Catalog encryption tool

Encrypts the catalog data files with a password. Everything happens in this browser tab, your files are not uploaded anywhere. Use the same password for every run, the catalog page asks for it when it opens.

Pick the folder that contains scan.glb, parts.json and the parts folder (and optionally an images folder).

Upload the contents of the ZIP (the .enc files) to your website repository, together with index.html. Do not upload the original, unencrypted files.
