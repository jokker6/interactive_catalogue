STEP to GLB converter

Converts your STEP files to GLB, which the catalog page loads many times faster than STEP. It runs in this browser tab, your files are not uploaded anywhere. Convert each part once, and again only when the part changes.

Pick several files at once, or a whole folder (for example your parts folder).

One file downloads as .glb, several files as one ZIP with a parts folder inside. Upload the GLB files next to your STEP files (into parts/). The catalog page uses a .glb automatically when it finds one with the same name as the STEP file, so parts.json does not need to change.
